Letter prompts.

LetterPrompt.m4a  = your "Find the letter..." recording. After it plays, the
                    computer voice says the letter. (Set in ../sounds.js as "prompt".)

Optional: record a whole prompt for a single letter and name it by the capital
letter, e.g. G.mp3 / G.wav / G.m4a. That file is used instead for that letter.
Turn on letterPrompts: true in ../sounds.js when you add these.
